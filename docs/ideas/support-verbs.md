# Support verbs

## One-liner
Spells that act on *allies and their spells*, so a skilled player can carry a newcomer without taking the spotlight from them.

## Verdicts so far
| Verb | Status | Notes |
|---|---|---|
| Priming a teammate's queue | rejected | Costs more to communicate than it saves; feels like sabotage |
| Lenses / conduits | promising | Objects that modify spells passing through them |
| Grand ritual (protect the caster) | promising | A big channeled spell; the caster is rooted |
| Sustained ritual (supporter's ongoing benefit) | promising | A continuous aura or zone maintained by the supporter |
| Targeted ally shields / enhancements | promising | Shields placed on allies or at arbitrary points, not centered on yourself |
| Single-target healing | promising | Heal *one* ally without splash |
| Friendly-fire avoidance shaping | promising | A deliberate way to spare allies; accidental friendly fire stays |
| Rescue movement (tether, swap, yank) | promising | |
| Drawing attention (decoys, vortices, taunts) | promising | |
| Restoring non-health resources | depends | Only if the game has such resources (see casting-rhythm) |
| Deliberate ally empowerment | conditional | Only through an explicit setup, never by accidental hits |

## Costs & risks
Spells become harder to read in chaotic fights. Support must not turn into a passive heal-bot.

## Open questions
- What makes support *skillful*: aim, timing, positioning, prediction?
- How do targeted ally spells work with mouse aim? Snap-to-ally, or a modifier?
