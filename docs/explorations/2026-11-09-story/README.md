# Story candidates for the journeyman's circuit (2026-11-09)

The user asked for agents to write high-level story beats and progression from the stand-in map and the journeyman's circuit, go back and forth with editors, and pick the strongest. **Nothing here is canon.** The lore is the user's, and these are options to react to on the [Story Review page](https://claude.ai/artifact/Tkkn1SucsWjoESkJW5grdf) (`tools/story-review/`).

The user's steer: the Pokémon echo is only the feel of mastering one element at a time in each new land, not the whole pattern. The academy-vein twist is open to replacement. The opening just has to work as a game opening.

## How it was made

- `00-brief.md`: the brief every writer got.
- `01-the-obvious.md`: an agent wrote the five most predictable plots and a 50-item ban list, given to every writer.
- `candidates/`: four writers, isolated, each with an assigned engine (`case`, `season`, `rival`, `oath`). Rounds `-r1` to `-r3`. `-r3` is the finished version.
- `editors/`: each candidate had its own story editor and game editor, who only saw that candidate.
- `audit-r1.md`, `audit-r2.md`: an agent compared all four, only to find overlaps. Writers were told what to replace without being told what the others contained.
- `judging/`: three judges read the finished stories under shuffled letters, each with one lens. P was oath, Q season, R case, S rival.

## Result

**Your Go** (`rival`) won with 122 of 150, first for the player and builder judges. **The Flitting Year** (`season`) had 107 and was the creator judge's first choice. **Before All the People** (`oath`) had 101, **What He Had on Him** (`case`) 84.

Main caution on the winner: the wells barely matter in it, and attuning is what the user said they liked. Biggest risk: four rival casters have to be fun to lose to.
